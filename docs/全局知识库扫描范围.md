# 全局知识库扫描范围

> 本文档是「获取知识库」功能**全局层**扫描的权威规格：knowledge 插件
> （`packages/knowledge/src/scan.ts`）按本文档实现。
> 配套文档：`docs/项目知识库扫描范围.md`（项目层）。
> 设计来源：《全局知识库.md》分类表，此处固化为可执行的扫描规格。

## 1. 扫描根

全局层扫描**不依赖 workspace**（Remote 方法 `knowledge/generate` 的
`scope='global'` 分支忽略 workspace 参数）。扫描根 = DSH home
（`$DSH_HOME`，缺省 `~/.dsh`）加少量只读系统信息源。

## 2. 排除规则

| 排除项 | 说明 |
|---|---|
| `~/.dsh/sessions/`、`~/.dsh/storages/`、`~/.dsh/usage-stats/` | 会话/运行时数据，不构成知识 |
| `~/.dsh/knowledge/`（含 `global/`） | 知识库自身落盘，避免自我循环 |
| `~/.dsh/profiles/*/node_modules/` | 依赖目录 |
| `.env`、`*secret*`、`*credential*`、`*.key` | 密钥类文件一律排除 |
| 二进制/超大文件 | 单个文件 > 256 KB 跳过；非 UTF-8 文本跳过 |

## 3. 分类 → 扫描源 → 提取重点

| 分类 `category` | 扫描源 | 提取重点 |
|---|---|---|
| `environment` | `$DSH_HOME/settings.yaml`、`$DSH_HOME/profiles/*/package.json`（已装插件清单）、`/etc/os-release`、`$HOME/.bashrc`（仅 `alias` 行） | DSH 配置、插件栈、OS 发行版、shell 别名 |
| `conventions` | `$DSH_HOME/cordis.patch.yml`（若存在）、`$DSH_HOME/profiles/*/cordis.patch.yml`（若存在） | 全局组合层约定、profile 补丁偏好 |

> `user-profile`（沟通语言/风格/偏好）无文件可扫，走**引导式问答**，
> 不在扫描范围内——全局「获取知识库」不产出该分类。

## 4. 提取规则（无 LLM，确定性提取）

每个扫描源生成**一条**知识条目：

| 字段 | 取值 |
|---|---|
| `id` | 自动生成 `kb-YYYYMMDD-NNN`（当日序号递增） |
| `scope` | `global` |
| `category` | 按第 3 节分类表（**映射**：`environment → fact`、`conventions → convention`，条目 schema 仅允许五类） |
| `tags` | `[语义分类, 源名, 'scanned']`（如 `['environment','settings.yaml','scanned']`；语义分类原样保留在 tags 首位） |
| `title` | 源名：`~/.dsh/settings.yaml`、`~/.dsh/profiles/web/package.json`、`/etc/os-release`、`~/.bashrc`、`~/.dsh/cordis.patch.yml` 等 |
| `body` | 摘要：`settings.yaml` / `cordis.patch.yml` 全文（≤ 8 KB）；`package.json` 只取 `dependencies` 键名列表（插件清单）；`os-release` 只取 `NAME=`、`VERSION=`、`PRETTY_NAME=` 行；`~/.bashrc` 只取 `alias ` 开头的行 |
| `source` | 源文件绝对路径（幂等键：`source` + `scope`） |
| `created` / `lastUsed` | 扫描当日日期 |
| `confidence` | `0.6` |
| `status` | `raw` |

特殊规则：

- `settings.yaml`、`cordis.patch.yml` 为**小 YAML/文本**：全文进 body（防
  止 YAML 解析破坏 frontmatter 的负担大于收益），上限 8 KB；
- `profiles/*/package.json`：同一目录下多个 profile 各生成一条，body
  只列 `dependencies` 键名（不含版本号，版本易变）；
- `/etc/os-release`、`~/.bashrc` 读取失败（权限/不存在）时**静默跳过**，
  不报错——全局环境差异大，部分源缺失是常态；
- 命令采集（`nvidia-smi`、`docker ps` 等）**不在本版范围**（设计文档中
  列为可选），如需扩展见第 7 节。

## 5. 输出

与项目层一致：`{ scanned, generated, skipped, entries }`。

## 6. 幂等与增量

- 幂等键 `source` + `scope`：重复点击不产生重复条目；
- 只新增，绝不覆盖/删除既有条目；人工整理不受影响。

## 7. 可选扩展（本版不实现）

- 只读命令采集：`nvidia-smi`、`docker ps`、`ss -tlnp` 输出写入
  `environment` 分类（需在插件配置中显式开启，默认关闭）；
- `user-profile` 引导式问答（无文件源，走交互式表单）。
