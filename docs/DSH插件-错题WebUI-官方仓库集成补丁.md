## 0. 包对照表（独立 workspace → 官方仓库）

| 独立 workspace 包 | 官方仓库落点（packages/ 下） | 说明 |
|---|---|---|
| `@dsh-plugins/errata` | `packages/errata`（`@deepseek-ai/dsh-errata`） | 宿主：工具 + 预警（agent 平面）+ Remote 服务（host 平面） |
| `@dsh-plugins/knowledge` | `packages/knowledge`（`@deepseek-ai/dsh-knowledge`） | 宿主：kb.* 工具（agent 平面）+ Remote 服务（host 平面） |

> 说明：独立 workspace 内的 Remote/Typert 描述符（`src/typert.host.ts`、`src/typert.remote-client.ts`）为**手写对齐官方生成格式**（`Generated by @deepseek-ai/dsh-typert-generator` 的格式、strict + zod v4 codec）。迁入官方仓库后应删除手写文件、改由 `typert-generator` 构建期生成（删除 `src/typert.host.ts` 并在源码 `@Remote` 装饰器上保持签名一致即可；生成产物与手写文件结构相同）。
>
> **注册方式（P3-11 定案）**：host 入口（`./host`）在 `apply` 内**手工 `ctx.typert.register(TYPERT)`**（注入 `typert` 服务，register 内部经 `ctx.effect` 管理生命周期），**不依赖** typert-loader 扫描 `./typert`；包 `exports` 因此**不声明 `./typert`**（避免 loader 与手工注册双注册冲突）。`ctx.typert.register` 接受 `TypertContribution`（`{package, face, schemas, model, invocations}`），即手写 manifest 的形状。

## 1. 宿主行（web-app/cordis.patch.yml）

Remote 服务是 **host 平面**服务（像 `plugin-inventory` 一样独立挂载），而 errata/knowledge/lesson-promote 主入口是 **agent 平面**（`inject: [agents, tools]`，Web profile 里按会话挂载）。因此三包各拆了独立 host 入口（`./host` 导出），在 web 组合的 host 平面插入：

```yaml
- id: errata-host
  name: '@deepseek-ai/dsh-errata/host'

- id: knowledge-host
  name: '@deepseek-ai/dsh-knowledge/host'

- id: lesson-promote-host
  name: '@deepseek-ai/dsh-lesson-promote/host'
```

依赖关系：`errata-host` 的晋级动作可选依赖 `ctx.lessonPromote`（由 `lesson-promote-host` 提供）；未挂载时 promote 方法返回「lesson-promote 插件未启用」，其余能力不受影响。三个 host 入口均注入 `typert` 服务（由 typert-loader 提供，host 平面必有）。

## 3. 聚合引用（tsconfig.client.json）

官方仓库的客户端 tsconfig 聚合需加入两个新包（各包自带浏览器面 tsconfig：`jsx: react-jsx`、`lib: [ES2022, DOM, DOM.Iterable]`）：

```jsonc
{
  "references": [
    // ...既有 client 包
    { "path": "packages/client/ui-settings-errata" },
    { "path": "packages/client/ui-settings-knowledge" }
  ]
}
```

## 5. 客户端产物（tsdown clientBundle）

两个客户端包沿用官方 client 包构建链（`scripts.bundle: tsdown`），产物 `client.js` 由 web 端 modules 行扫入 `window.__DSH_BOOT__`。`dsh.client` 声明与官方一致：

```jsonc
{
  "dsh": { "client": { "platform": "web", "inject": [
    "@deepseek-ai/dsh-api-remotes",
    "@deepseek-ai/dsh-client-runtime",
    "@deepseek-ai/dsh-client-ui-settings",
    "@deepseek-ai/dsh-client-locale"
  ] } }
}
```
