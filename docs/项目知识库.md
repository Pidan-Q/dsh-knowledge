## 项目库分类 → 扫描范围

| 分类           | 扫描源（按优先级）                                           | 提取重点                                         | 排除/注意                                  |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------- | :----------------------------------------- |
| `architecture` | `docs/architecture*.md`、`docs/adr/`、`README.md`、`AGENTS.md` | 模块划分、数据流、技术栈选型、架构决策           | 不扫源码实现细节                           |
| `deployment`   | `docker-compose.yml`、`Dockerfile`、`package.json`、`README.md`、`.env.example`、`docs/deploy*.md`、`Makefile` | 端口映射、启动命令、环境变量、依赖版本、服务拓扑 | 不扫 `.env`（含密钥），只扫 `.env.example` |
| `devices`      | `docs/devices*.md`、`config/*.yaml`、`ha-config/`、`*.json`（设备清单） | 实体 ID、类型、API 端点、传感器、设备状态        | 不扫运行时状态文件                         |
| `conventions`  | `AGENTS.md`、`.editorconfig`、`CONTRIBUTING.md`、`docs/conventions*.md`、`tsconfig.json`、`eslint.config.*` | 命名规范、代码风格、提交规范、目录约定           | 不扫 `.gitignore` 之类纯工具文件           |
| `glossary`     | `docs/glossary*.md`、`README.md`、`docs/domain*.md`          | 业务术语、缩写、领域黑话、专有名词定义           | 通用词典不提取                             |
| `decisions`    | `docs/adr/`、`docs/decisions*.md`、`CHANGELOG.md`、`docs/rfcs/` | 选型记录、取舍背景、替代方案、时间线             | 不扫 issue 讨论                            |
